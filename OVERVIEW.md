Office Explorer adds a Windows Explorer style file tree and integrated Office document viewer to the right sidebar of Paseo workspaces.

It highlights spreadsheet, document, and PDF files with color-coded badges (`XLS`, `CSV`, `DOC`, `PDF`, `{ }`) and connects agent validation reports directly to the document viewer. When an agent reports issues through the `report_office_issues` tool call, the sidebar displays error count badges beside affected files in the directory tree and lets you jump directly from the chat card to the exact Excel worksheet cell or document page.
